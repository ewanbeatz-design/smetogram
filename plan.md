# План MVP «Сметограм»

## Цель
Дать пользователю первый рабочий кабинет для ведения ремонтных объектов: быстро увидеть состояние проектов, открыть объект и собрать смету с мгновенными расчётами.

## Границы первой версии
Включено: список проектов, создание проекта, карточка объекта, статусы, демо-данные, категории сметы, строки работ, редактирование, добавление и удаление, расчёт итогов, адаптивный интерфейс и локальное сохранение в браузере.

Отложено на следующий этап: распознавание PDF и фото-обмер, роли и приглашения, чат, ЭП по SMS, генерация документов, график, приёмка и платежи. Эти функции потребуют серверных контрактов, хранилища файлов, аудита и юридически корректных интеграций.

## Архитектура
- `client/src/App.tsx` — состояние MVP и основные пользовательские сценарии.
- `client/src/index.css` — дизайн-система «Тёплый рабочий кабинет» и responsive breakpoints.
- `client/src/pages/` — сохранённые стартовые страницы шаблона; основной сценарий подключён в корневом роуте.
- `server/`, `drizzle/` — подготовленная серверная и DB-основа для следующего этапа; на MVP данные не отправляются на сервер.

## Выбранный способ отдачи
CSR/SPA на React + Vite с подготовленным Express API. Статические ассеты собираются Vite, динамические бизнес-операции будут вынесены в `/api` при подключении сохранения на сервере. Персональные данные и сметы не кэшируются.

## Проверка
Проверить TypeScript (`pnpm check`), продакшен-сборку (`pnpm build`) и доступность dev-сервера на порту 3000. При ошибках исправить исходники и повторить только затронутую проверку.
